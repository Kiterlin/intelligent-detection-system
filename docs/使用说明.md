## 系统概述

**智能目标检测系统** 是一个基于YOLO的企业级AI检测应用，提供图片和视频的目标检测功能。

### 核心功能

- ✅ **用户认证**: 注册、登录、权限管理
- ✅ **模型管理**: 上传、激活、管理YOLO模型
- ✅ **图片检测**: 实时检测图片中的目标对象
- ✅ **视频检测**: 异步处理视频文件
- ✅ **检测历史**: 查看、管理、下载历史检测记录
- ✅ **管理后台**: 用户管理、模型管理、数据统计

### 技术架构

```
前端: Vue 3 + Element Plus + Vite
后端: FastAPI + SQLAlchemy + Celery
AI引擎: PyTorch + Ultralytics YOLO
消息队列: Redis
数据库: SQLite (开发) / PostgreSQL (生产)
```

## 安装步骤

### 第一步：克隆项目

```bash
# 进入工作目录
cd /path/to/your/workspace

# 如果是从Git仓库克隆
git clone <repository-url>
cd project

# 如果是从压缩包解压
unzip project.zip
cd project
```

### 第二步：安装后端依赖

```bash
# 进入后端目录
cd backend

# 创建Python虚拟环境
python3.11 -m venv venv

# 激活虚拟环境
# Linux/macOS:
source venv/bin/activate
# Windows:
# venv\Scripts\activate

# 升级pip
pip install --upgrade pip

# 安装依赖
pip install -r requirements.txt

# 验证安装
python -c "import fastapi; import torch; print('Backend dependencies installed successfully!')"
```

**预期输出**: `Backend dependencies installed successfully!`

### 第三步：初始化数据库

```bash
# 确保在backend目录下，虚拟环境已激活

# 运行数据库迁移
alembic upgrade head

# 验证数据库
ls -lh water_detection.db
```

**预期结果**: 生成 `water_detection.db` 文件（约几KB大小）

### 第四步：安装Redis

#### Ubuntu/Debian
```bash
sudo apt update
sudo apt install redis-server
sudo systemctl start redis-server
sudo systemctl enable redis-server
```

#### macOS
```bash
brew install redis
brew services start redis
```

#### Windows (WSL2推荐)
```bash
# 在WSL2中
sudo apt install redis-server
sudo service redis-server start
```

#### 验证Redis
```bash
redis-cli ping
```
**预期输出**: `PONG`

### 第五步：安装前端依赖

```bash
# 回到项目根目录
cd ../frontend

# 安装npm依赖
npm install

# 验证安装
npm list vue element-plus
```

**预期输出**: 显示Vue 3和Element Plus版本信息

## 启动系统

系统需要启动**4个服务**，建议使用4个终端窗口。

### 终端1: 后端服务 (FastAPI)

```bash

cd /path/to/project/backend

# 激活虚拟环境

# 启动FastAPI服务
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## 首次使用指南

### 步骤1: 注册管理员账号

1. 浏览器访问: http://localhost:5173
2. 点击"立即注册"
3. 填写信息:
   - 用户名: `admin` (示例)
   - 邮箱: `admin@example.com`
   - 密码: `admin123` (请使用强密码)
4. 点击"注册"按钮

**注意**: 第一个注册的用户会自动成为管理员

### 步骤2: 登录系统

1. 使用刚才注册的账号登录
2. 成功后会跳转到首页

### 步骤3: 上传YOLO模型

**重要**: 系统需要至少一个YOLO模型才能进行检测！

#### 3.1 获取YOLO模型

**方式1: 使用预训练模型** (推荐快速开始)
```bash
# 在backend目录下
cd /path/to/project/backend
source venv/bin/activate

# 下载YOLOv8n模型（约6MB）
python -c "
from ultralytics import YOLO
model = YOLO('yolov8n.pt')  # 自动下载
print('Model downloaded to: ~/.cache/ultralytics/')
"

# 复制到uploads目录
mkdir -p uploads/models
cp ~/.cache/ultralytics/yolov8n.pt uploads/models/
```

**方式2: 使用自己的模型**
- 准备你训练好的 `.pt` 或 `.pth` 模型文件

#### 3.2 通过管理后台上传

1. 点击右上角用户名 → "管理后台"
2. 左侧菜单选择"模型管理"
3. 点击"上传模型"按钮
4. 填写模型信息:
   - **模型名称**: `YOLOv8n` (示例)
   - **模型版本**: `v8.0` (示例)
   - **描述**: `COCO预训练的YOLOv8 nano模型`
5. 点击上传区域，选择 `yolov8n.pt` 文件
6. 点击"确定"上传

**等待上传完成** (几秒到几分钟，取决于文件大小)

#### 3.3 激活模型

1. 在模型列表中找到刚上传的模型
2. 点击"激活"按钮
3. 状态变为绿色"已激活"

✅ 模型上传完成！现在可以开始检测了

---

### 步骤4: 测试图片检测

#### 4.1 准备测试图片

使用任意包含物体的图片，例如：
- 风景照片
- 动物照片
- 交通场景
- 人物照片

支持格式: JPG, JPEG, PNG, BMP
大小限制: 最大20MB

#### 4.2 执行检测

1. 点击右上角 → "开始检测"
2. 拖拽图片到上传区域，或点击选择文件
3. 确认文件信息显示正确
4. 选择检测模型（刚才激活的模型）
5. 调整参数（可选）:
   - **置信度阈值**: 0.25-0.5 (默认0.5)
   - **IOU阈值**: 0.4-0.5 (默认0.45)
6. 点击"开始检测"按钮

**等待3-10秒** (取决于图片大小和CPU/GPU性能)

#### 4.3 查看结果

检测完成后会显示:
- ✅ 标注后的图片（边界框+标签）
- ✅ 检测统计（对象数量、处理时间）
- ✅ 对象列表（类别、置信度、坐标）
- ✅ 下载按钮（保存结果）

---

### 步骤5: 测试视频检测

#### 5.1 准备测试视频

使用短视频进行测试：
- **推荐**: 10-30秒的短视频
- 支持格式: MP4, AVI, MOV
- 大小限制: 最大500MB

#### 5.2 执行检测

1. 在检测页面上传视频文件
2. 选择模型和参数
3. 点击"开始检测"
4. 观察进度条更新:
   - 等待处理 (20%)
   - 处理中 (60%)
   - 已完成 (100%)

**处理时间**: 取决于视频长度和分辨率
- 30秒视频 ≈ 1-3分钟
- 1分钟视频 ≈ 2-5分钟

#### 5.3 查看结果

- ✅ 播放检测后的视频
- ✅ 查看检测信息
- ✅ 下载结果视频

---

### 步骤6: 查看检测历史

1. 点击右上角 → "检测历史"
2. 查看所有历史记录
3. 使用筛选功能:
   - 按类型筛选（图片/视频）
   - 按状态筛选（已完成/处理中/失败）
4. 操作选项:
   - **查看**: 打开详情对话框
   - **下载**: 下载检测结果
   - **删除**: 删除记录
   - **批量删除**: 选择多条记录删除

#### 2. 检测功能

访问: 右上角 → "开始检测"

**图片检测**:
```
上传图片 → 选择模型 → 配置参数 → 开始检测 → 查看结果 → 下载
```

**视频检测**:
```
上传视频 → 选择模型 → 配置参数 → 开始检测 → 等待处理 → 查看结果 → 下载
```

**参数说明**:

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 置信度阈值 | 0.0-1.0 | 0.5 | 控制检测结果的最小置信度，值越高过滤越严格 |
| IOU阈值 | 0.0-1.0 | 0.45 | 非极大值抑制的IOU阈值，用于去除重叠检测框 |

**建议值**:
- 精确检测: 置信度0.5-0.7, IOU 0.4-0.5
- 全面检测: 置信度0.25-0.4, IOU 0.3-0.4

#### 3. 历史管理

访问: 右上角 → "检测历史"

功能:
- 浏览所有检测记录
- 按类型/状态筛选
- 分页查看（10/20/50/100条每页）
- 查看详细结果
- 重新下载结果
- 删除不需要的记录

## 常见问题

### Q1: 启动后端时报错 "Address already in use"

**原因**: 端口8000已被占用

**解决方案**:
```bash
# 方式1: 查找并结束占用进程
lsof -i :8000
kill -9 <PID>

# 方式2: 使用其他端口
uvicorn app.main:app --reload --port 8001

# 前端需要相应修改API地址
# frontend/.env.development
# VITE_API_BASE_URL=http://localhost:8001/api/v1
```

---

### Q2: Celery启动失败 "Cannot connect to redis"

**原因**: Redis服务未启动或连接失败

**解决方案**:
```bash
# 检查Redis状态
redis-cli ping

# 如果无响应，启动Redis
# Linux:
sudo systemctl start redis-server

# macOS:
brew services start redis

# 手动启动:
redis-server
```

---

### Q3: 前端页面空白或报错

**原因**: 前端构建问题或API连接失败

**解决方案**:
```bash
# 1. 清除缓存
cd frontend
rm -rf node_modules dist .vite
npm install

# 2. 检查后端是否启动
curl http://localhost:8000/health

# 3. 检查浏览器控制台错误
# F12 → Console标签页
```

---

### Q4: 上传模型后检测失败

**原因**: 模型文件损坏或格式不兼容

**解决方案**:
```bash
# 验证模型文件
cd backend
source venv/bin/activate

python -c "
from ultralytics import YOLO
model = YOLO('uploads/models/your_model.pt')
print('Model loaded successfully!')
"

# 如果报错，重新下载或训练模型
```

---

### Q5: 视频检测一直处于"处理中"

**原因**: Celery worker未启动或崩溃

**解决方案**:
```bash
# 1. 检查Celery worker是否运行
ps aux | grep celery

# 2. 查看Celery日志
# 在Celery终端查看错误信息

# 3. 重启Celery worker
# Ctrl+C停止，然后重新启动
celery -A app.celery_app worker --loglevel=info

# 4. 检查任务队列
redis-cli
> LLEN celery
> KEYS *
```

---

### Q6: GPU加速不生效

**原因**: CUDA未正确安装或PyTorch版本不匹配

**检查GPU可用性**:
```bash
cd backend
source venv/bin/activate

python -c "
import torch
print('CUDA available:', torch.cuda.is_available())
print('CUDA version:', torch.version.cuda)
print('GPU count:', torch.cuda.device_count())
if torch.cuda.is_available():
    print('GPU name:', torch.cuda.get_device_name(0))
"
```

**如果CUDA不可用**:
- 检查NVIDIA驱动是否安装
- 重新安装PyTorch (GPU版本)
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

---

### Q7: 移动端页面显示异常

**原因**: 响应式样式未生效

**解决方案**:
- 清除浏览器缓存
- 使用Chrome DevTools测试（F12 → 设备模拟）
- 确保前端代码最新（git pull）

---

### Q8: 检测结果不准确

**原因**: 参数设置不当或模型不适合场景

**优化建议**:
1. **调整置信度阈值**:
   - 漏检 → 降低阈值 (0.3-0.4)
   - 误检 → 提高阈值 (0.6-0.7)

2. **调整IOU阈值**:
   - 重复框 → 提高IOU (0.5-0.6)
   - 遗漏框 → 降低IOU (0.3-0.4)

3. **使用专用模型**:
   - 通用场景 → YOLOv8n/s (COCO)
   - 特定领域 → 自己训练的模型

## 停止系统

### 优雅停止

在每个终端按 `Ctrl + C` 停止对应服务：

1. **前端**: Ctrl + C (立即停止)
2. **Celery**: Ctrl + C (等待当前任务完成)
3. **后端**: Ctrl + C (等待请求完成)
4. **Redis**: Ctrl + C 或保持运行

### 完全清理

```bash
# 停止所有相关进程
pkill -f uvicorn
pkill -f celery
pkill -f redis-server

# 清理临时文件（可选）
cd backend
rm -rf __pycache__ .pytest_cache

cd ../frontend
rm -rf node_modules/.vite
```
