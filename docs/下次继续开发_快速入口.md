## 💡 关键提示

### Stage 5 注意事项

1. **WeasyPrint 系统依赖**
   - 必须安装 `libpango` 和 `libcairo`
   - macOS 用户使用 Homebrew 安装

2. **中文字体问题**
   - HTML 模板中指定中文字体族
   - 测试 PDF 中文显示

3. **Celery 队列隔离**
   - 使用专用 `reports` 队列
   - 避免阻塞 `detection` 队列

4. **性能优化**
   - 大数据量使用分页查询
   - 使用数据库索引
   - 及时清理临时文件

5. **错误处理**
   - 捕获 PDF 生成错误
   - 记录详细日志
   - 提供 HTML 备选方案

## 📞 问题排查

### 常见问题

**Q1: WeasyPrint 安装失败？**
```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install libpango-1.0-0 libpangocairo-1.0-0 libgdk-pixbuf2.0-0 libffi-dev shared-mime-info

# 然后重新安装
pip install weasyprint
```

**Q2: PDF 中文显示为空框？**
```html
<!-- 在 HTML 模板中指定中文字体 -->
<style>
body {
    font-family: "Microsoft YaHei", "SimHei", "STHeiti", sans-serif;
}
</style>
```

**Q3: Celery 任务不执行？**
```bash
# 检查 Worker 状态
celery -A app.core.celery_app status

# 检查队列路由配置
# backend/app/core/celery_app.py

# 重启 Worker
celery -A app.core.celery_app worker -Q reports --loglevel=info
```

**Q4: 报告生成很慢？**
- 检查数据库索引
- 使用数据聚合缓存
- 限制查询数据量
- 优化 SQL 查询
