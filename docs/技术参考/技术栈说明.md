## 后端技术栈

### Web 与 API
- **FastAPI 0.104**：主框架，提供依赖注入、OpenAPI 文档与异步路由。
- **Uvicorn 0.24**：ASGI 服务器，`start.sh` 默认以 `--reload` 启动开发环境。
- **Pydantic 2 + pydantic-settings**：请求/响应模型与配置管理（`.env`）。
- **Starlette 中间件**：通过 FastAPI 自带 CORS、异常处理等。

### 数据访问层
- **SQLAlchemy 2.0**：声明式 ORM；所有表（数据集、告警、报告、标注、训练等）均定义在 `backend/app/models/`。
- **Alembic 1.12**：数据库迁移（`backend/alembic/versions`）；`init_postgres.sql` 可初始化 Docker 数据库。
- **asyncpg / aiosqlite / psycopg2-binary**：支持 PostgreSQL（推荐）与 SQLite（快速体验）。

### 认证与安全
- **python-jose[cryptography]、passlib[bcrypt]**：JWT 颁发、密码哈希。
- **python-multipart**：处理上传文件（图片 / 视频 / 报告模板）。

### 异步任务、缓存与配置
- **Celery 5.3**：三个队列（detection、reports、training），见 `backend/app/celery_app.py`。
- **Redis 5**：消息代理 + 任务结果 + 部分缓存（`core/cache.py`）。
- **Loguru**：统一日志格式；`logs/backend.log`、`logs/celery.log` 供排障。

### AI / 数据服务
- **PyTorch 2.1 + torchvision 0.16**：YOLO 推理与训练基础。
- **Ultralytics 8.0.220**：YOLOv8 推理封装（训练脚本见 `app/utils/yolo_trainer.py`）。
- **OpenCV 4.8、Pillow 10**：图像/视频处理、缩放、帧抽取。
- **自研服务**：
  - `services/report_generator.py`：Jinja2 + WeasyPrint 输出 PDF/HTML。
  - `services/data_aggregator.py`：汇总检测历史、告警、模型使用统计。
  - `services/annotation_converter.py` + `services/label_studio_service.py`：Label Studio 集成与格式转换。

### 测试与质量
- **pytest 7.4**：单元/服务级测试（`backend/tests/`）。
- **httpx**：异步 HTTP 客户端（调用外部 webhook 或 Label Studio）。

## 前端技术栈

### 基础框架
- **Vue 3.3 (Composition API)**：用户端与管理端复用同一 SPA。
- **Vite 5**：开发/构建工具，默认端口 `5173`。
- **Vue Router 4**：路由与权限守卫（`router.beforeEach` 校验 `requiresAdmin`）。
- **Pinia 2**：状态管理，包含 `auth`/`user`/`detection` 三大 store。

### UI 与可视化
- **Element Plus 2.4**：UI 组件库（表单、表格、Steps、Drawer 等）。
- **Element Icons + 自定义 SVG**：统一图标。
- **ECharts 6 + vue-echarts 8**：仪表盘饼图、训练曲线等。
- **tailwindcss 3.4**：快速布局与主题变量，配合 `src/assets/styles/`。
- **tsParticles**：登录页、Home 页的粒子背景。
- **vue-cropper**：头像或图片裁剪（Profile 页面使用）。

### 网络与工具
- **Axios**：`src/api/*` 统一封装，自动注入 Token、处理 blob 下载。
- **ESLint + eslint-plugin-vue**：代码风格检查。

## AI 与训练管线

1. **检测**：前端上传图片/视频 → `/api/v1/detect/image|video` → 直接推理或 Celery 任务。
2. **数据集管理**：`/datasets` 提供批量上传、批量检测（Celery chain 逐文件处理）。
3. **标注**：`/annotations/tasks` 与 Label Studio 项目打通，可导入检测结果生成预标注。
4. **报告生成**：`report_tasks.py` 调用 `ReportGenerator` 渲染模板并导出 PDF/HTML。
5. **模型训练**：管理员在前端挑选已完成的标注任务 + 基础模型，后端 Celery worker 触发 `training_tasks.py`，实时更新日志和指标。

## 数据库、缓存与外部服务

| 组件           | 默认配置                        | 说明 |
|----------------|---------------------------------|------|
| PostgreSQL 15+ | `postgresql+asyncpg://`         | 生产环境推荐；开发可用 SQLite DB |
| Redis 5        | `redis://localhost:6379`        | Celery broker + 结果 + dashboard 缓存 |
| Label Studio   | `docker-compose.label-studio.yml` | 标注项目管理，`annotations.py` 与其 REST API 通讯 |

## 开发与部署工具

- **Docker / docker-compose**：一键启动数据库、Redis、Label Studio。
- **start.sh / stop.sh**：本地快捷脚本，启动 FastAPI、Vite、Celery 三个进程。
- **Flower（可选）**：若需监控 Celery，可手动运行 `celery -A app.celery_app flower`。
- **Git Hooks（可自定义）**：建议在提交前运行 `pytest` 与 `npm run lint`。
