## 📊 项目概览

**智能目标检测系统** 是一个企业级AI检测应用，采用前后端分离架构。目前已完成认证系统、管理后台、AI检测核心和用户检测界面的全部功能，包括UI/UX优化和代码质量保障，准备进入系统优化与部署阶段。

## 🔧 技术栈

### 后端
- **框架**: FastAPI 0.104+
- **数据库ORM**: SQLAlchemy 2.0 (异步)
- **数据库**: SQLite (开发) / PostgreSQL (生产)
- **迁移工具**: Alembic
- **认证**: JWT + Bcrypt
- **AI框架**: PyTorch 2.1.1 + Ultralytics YOLO
- **异步任务**: Celery 5.3.4 + Redis
- **图像处理**: OpenCV 4.8.1
- **文件处理**: aiofiles
- **Python版本**: 3.11+

### 前端
- **框架**: Vue 3.3+ (Composition API)
- **构建工具**: Vite 5.0+
- **UI库**: Element Plus 2.4+
- **状态管理**: Pinia 2.1+
- **路由**: Vue Router 4.2+
- **HTTP客户端**: Axios 1.6+
- **图表库**: ECharts + vue-echarts
- **Node版本**: 18+

### 基础设施
- **版本控制**: Git
- **消息队列**: Redis
- **文件存储**: 本地文件系统（开发）/ 对象存储（生产）

## 🚀 如何运行

### 完整系统启动

#### 1. 后端服务
```bash
cd backend
source venv/bin/activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

#### 2. Redis服务
```bash
redis-server
# 或
sudo service redis-server start
```

#### 3. Celery Worker
```bash
cd backend
source venv/bin/activate
celery -A app.celery_app worker --loglevel=info
```

#### 4. 前端服务
```bash
cd frontend
npm install
npm run dev
```

### 访问地址

- **前端应用**: http://localhost:5173
- **后端API文档**: http://localhost:8000/docs
- **管理后台**: http://localhost:5173/admin/dashboard
- **检测页面**: http://localhost:5173/detection
- **历史页面**: http://localhost:5173/detection-history

### 测试流程

1. **上传模型**:
   - 管理员登录 → 管理后台 → 模型管理
   - 上传YOLO模型文件（.pt/.pth）
   - 激活模型

2. **执行检测**:
   - 用户登录 → 开始检测
   - 选择文件和模型
   - 调整参数并执行
   - 查看结果
