**# 角色：[专业身份]** 你是一位资深的软件系统专家，擅长使用HTML、CSS和JavaScript为项目系统设计创建高级好看的网页，同时精通现代前端框架（如Vue.js）和UX/UI设计原则。

**## 任务概述** 请为我设计并创建一个**目标检测系统的前端登录页面**。这个**登录页 (HTML/CSS/JS)** 应该作为一个专业、安全且富有科技感的门户，用于验证用户（包括普通用户和管理员）的身份。它需要提供一个无缝的、零摩擦的登录体验，同时通过视觉设计传达系统的“深海科技”主题和专业性。

**## 内容规划** 请按照以下步骤规划内容：

**[思考/分析]：** 目标是创建一个能平衡品牌叙事和功能操作的登录页。用户是专业人士（或管理员），因此界面必须简洁、专业，不能有干扰。我们将采用**左右分屏 (Split-screen)** 布局：左侧用于沉浸式品牌展示（“深海科技”主题），右侧用于功能性登录表单（“零摩擦操作”）。此设计能立即传达系统的双重属性：既是强大的技术平台，又是易于使用的工具。

**[方案设计]：**

1. **布局：** 采用左右分屏布局。
2. **左侧（品牌区）：** 占比 50%-60%，用于展示动态视觉背景和Slogan，建立情感连接。
3. **右侧（功能区）：** 占比 40%-50%，使用浅色背景，放置一个垂直居中的表单卡片，用于用户输入。
4. **表单设计：** 包含系统标题（例如“欢迎回来”）、邮箱地址输入框、密码输入框（带显示/隐藏切换）、“记住我”复选框、“忘记密码”链接、主登录按钮，以及一个“还没有账户? 请联系管理员”的辅助说明。

**[实现细节]：**

1. **HTML结构：** 使用一个主容器 `<div class="login-container">`，内含 `<div class="brand-panel">` (左侧) 和 `<div class="form-panel">` (右侧)。
2. **左侧面板：** 使用CSS绝对定位在背景上叠加Logo和Slogan。背景使用 `particles.js` 或 Lottie/WebGL 实现动态“数字水波纹”或“声纳网格”效果。
3. **右侧面板：** 使用 Flexbox 布局（`display: flex`, `align-items: center`, `justify-content: center`）使表单卡片垂直和水平居中。
4. **表单卡片：** 使用 `border-radius` 和 `box-shadow` 创造柔和的浮动感。
5. **输入框：** 包含内嵌的图标（来自图标库），并使用 `:focus-within` 伪类在输入时高亮边框和图标。
6. **交互逻辑 (JS)：** 绑定表单提交事件，实现客户端实时验证（如邮箱格式）。在提交时，禁用按钮并显示加载中 (Spinner) 动画。根据API的成功/失败响应，显示成功跳转或在表单顶部动态插入错误提示条（Alert Banner）。

**## 设计风格**

- **整体风格：** 专业、简洁、现代的“深海科技 (Deep Tech)”风格。界面应体现高科技感、信任感和易用性，参考现代B端SaaS产品（如Azure, Datadog）的登录界面。
- **配色方案：**
  - **主色调 (品牌/左侧):** 深海蓝 (`#0A2E5B`)
  - **背景色 (表单/右侧):** 极浅灰 (`#F4F7FA`)
  - **强调色 (按钮/高亮):** 珊瑚橙 (`#FF7F50`) 或 亮青色 (`#00BFFF`)
  - **文字色:** 深灰 (`#34495E`) (用于表单), 白色 (用于左侧Slogan)
- **字体选择：** 清晰、现代的无衬线字体。首选 `Inter`，备选 `Roboto` 或 `Lato`。标题使用中粗体 (Medium)，正文使用常规 (Regular)。
- **视觉元素：** 左侧使用动态抽象背景（“数字水波纹”或“声纳网格”动画）。右侧表单输入框内嵌简洁的线条图标（如信封、锁）。
- **交互效果：**
  1. **输入框焦点：** 边框和图标变为强调色。
  2. **按钮悬停：** 轻微放大或颜色变亮。
  3. **按钮点击：** 显示加载中 (Spinner) 动画，按钮变为禁用状态。
  4. **错误提示：** 非侵入式提示条动态滑入，而不是使用 `alert()`。

**## 技术要求**

- **开发框架：** **TailwindCSS** (用于快速实现自定义的、原子化的样式，非常适合这种定制化设计) 或 Bootstrap 5 (用于标准布局和表单组件)。
- **脚本要求：** **Vue 3 (Composition API)** 或 React 18。使用 **Axios** 进行API（登录）请求。
- **响应式要求：** 必须完全响应式。在移动设备（< 768px）上，左右分屏布局应**折叠**：顶部显示品牌区（深色背景+Logo），下方显示功能区（浅色背景+表单卡片）。
- **性能考虑：** 左侧的动态背景动画必须轻量（使用优化的 Lottie 或 `particles.js`）。所有图像资源应被压缩。JS文件应被最小化和异步加载 (defer)。

**## 资源配置**

- **图片资源：** Logo 为自定义 SVG。左侧动态背景使用 LottieFiles 或 `particles.js` 库生成，不使用真实的图片或视频。
- **图标库：** **Material Icons (Google)** 或 **Heroicons** (Tailwind 团队出品)，确保图标风格简洁、统一。
- **外部引用：** Google Fonts (用于加载 `Inter` 字体)。

**## 交付标准**

- **代码质量：** 代码语义化 (HTML5)，CSS 遵循 BEM 规范（如果不用Tailwind），JS/Vue 遵循 ESLint 和 Prettier 规范。必须包含清晰的注释。
- **兼容性：** 兼容所有现代浏览器（Chrome, Firefox, Safari, Edge）的最新两个版本。
- **文件格式：** 交付包含 `index.html`, `style.css` (或 `main.js` + Vue/React 组件) 的完整项目文件结构。

**## 特殊要求**

- 登录表单的错误反馈必须是动态的（在表单顶部显示提示条），而不是使用浏览器默认的 `alert`。
- 密码输入框必须包含“显示/隐藏”切换功能。
- 辅助操作应引导用户“联系管理员”，而不是“立即注册”，以符合B端系统逻辑。
