## 📊 项目概览

**水下目标智能检测平台** 是一个企业级AI检测应用，采用前后端分离架构。目前已完成基础认证系统和管理后台功能，正准备进入AI检测核心功能的开发。

### 开发进度

```

Phase 2: 管理后台           ✅ 已完成 (2025-11-12)
Phase 3: AI检测核心         ⏳ 计划中
Phase 4: 用户检测界面       ⏳ 待启动
Phase 5: 系统优化与部署     ⏳ 待启动
```

## ✅ 已完成功能

### 1. 用户认证系统 (Phase 1)

**后端功能**:
- ✅ JWT Token认证机制
- ✅ Bcrypt密码哈希存储
- ✅ 用户注册、登录、密码修改
- ✅ 基于角色的访问控制 (RBAC: user/admin)
- ✅ Token自动刷新机制
- ✅ SQLAlchemy 2.0 异步ORM

**API端点**:
```

POST   /api/v1/auth/login           # 用户登录
GET    /api/v1/auth/me              # 获取当前用户信息
POST   /api/v1/auth/change-password # 修改密码
GET    /health                      # 健康检查
```

**前端功能**:
- ✅ 登录页面 (`/login`)
- ✅ 注册页面 (`/register`)
- ✅ 首页 (`/`)
- ✅ 个人中心 (`/profile`)
- ✅ 路由守卫（自动重定向未登录用户）
- ✅ Axios拦截器（自动Token管理）
- ✅ Pinia状态管理

**数据库表**:
- `users` 表：用户基本信息、角色、激活状态

- ✅ 静态文件服务 (`/uploads`)

**API端点**:
```
# 用户管理
GET    /api/v1/admin/users                      # 用户列表（分页、搜索、筛选）
POST   /api/v1/admin/users                      # 创建用户
GET    /api/v1/admin/users/{id}                 # 用户详情
PUT    /api/v1/admin/users/{id}                 # 更新用户
DELETE /api/v1/admin/users/{id}                 # 删除用户
POST   /api/v1/admin/users/batch/delete         # 批量删除用户
POST   /api/v1/admin/users/batch/update-status  # 批量更新状态

# 模型管理
POST   /api/v1/admin/models/upload              # 上传模型文件
GET    /api/v1/admin/models                     # 模型列表（分页、搜索）
GET    /api/v1/admin/models/{id}                # 模型详情
PUT    /api/v1/admin/models/{id}                # 更新模型信息
PATCH  /api/v1/admin/models/{id}/status         # 激活/停用模型
DELETE /api/v1/admin/models/{id}                # 删除模型
```

## 🔧 技术栈

### 后端

## 🚀 如何运行

### 环境要求
- Python 3.11+
- Node.js 18+
- SQLite (或 PostgreSQL)

### 后端启动

```bash
cd backend
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**访问地址**:
- API文档: http://localhost:8000/docs
- ReDoc文档: http://localhost:8000/redoc
- 健康检查: http://localhost:8000/health

### 前端启动

```bash
cd frontend
npm install
npm run dev
```

**访问地址**:
- 应用首页: http://localhost:5173
- 登录页面: http://localhost:5173/login
- 管理后台: http://localhost:5173/admin/dashboard

### 测试账号

**管理员账号** (需手动在数据库创建):
```sql
-- 更新用户角色为管理员
UPDATE users SET role = 'admin' WHERE username = 'your_username';
```
