## 🔧 技术亮点详解

### 1. 队列隔离架构

**设计理念**：不同业务使用独立队列，避免相互阻塞

```python
CELERY_TASK_ROUTES = {
    'app.tasks.detection_tasks.*': {'queue': 'detection', 'priority': 5},
    'app.tasks.report_tasks.*': {'queue': 'reports', 'priority': 3},
    'app.tasks.training_tasks.*': {'queue': 'training', 'priority': 1},
}
```

**Worker 部署**：
```bash
# 检测 Worker（高优先级，多并发）
celery -A app.core.celery_app worker -Q detection -c 4

# 报告 Worker（中等优先级）
celery -A app.core.celery_app worker -Q reports -c 2

# 训练 Worker（低优先级，GPU 专用）
celery -A app.core.celery_app worker -Q training -c 1 --pool=solo
```

### 2. Label Studio 集成方案

**架构**：
```
┌─────────────┐     REST API     ┌──────────────┐
│   后端 API   │ ←─────────────→ │ Label Studio │
└─────────────┘                  └──────────────┘
       ↓                                 ↓
  数据库存储                        文件存储
  (annotations)                   (标注项目)
```

**双向同步**：
1. 检测结果 → Label Studio 预标注
2. Label Studio 标注 → 数据库持久化
3. 数据库标注 → YOLO/COCO 导出

### 3. 数据准备自动化

**流程**：
```
1. 从数据库获取标注数据
   ↓
2. 按比例划分数据集 (train/val/test: 80/15/5)
   ↓
3. 复制图片到训练目录
   ↓
4. 转换标注格式（绝对坐标 → YOLO 归一化坐标）
   ↓
5. 生成 data.yaml 配置文件
   ↓
6. 准备完成，可开始训练
```

**坐标转换**：
```python
# 绝对坐标 (x1, y1, x2, y2)
x_center = ((x1 + x2) / 2) / image_width
y_center = ((y1 + y2) / 2) / image_height
width = (x2 - x1) / image_width
height = (y2 - y1) / image_height

# YOLO 格式: <class_id> <x_center> <y_center> <width> <height>
```

### 4. GPU Worker 优化

**挑战**：默认 Celery Worker（prefork pool）与 GPU 不兼容

**解决方案**：
- 使用 `--pool=solo` 单进程模式
- `--concurrency=1` 限制并发
- 独立 GPU Worker 专门处理训练任务

**效果**：
- ✅ 避免 CUDA 初始化冲突
- ✅ GPU 资源独占，训练稳定
- ✅ 不影响检测和报告任务

**启示**：测试投入物有所值

### 遇到的挑战

#### 1. GPU 多进程冲突 ⚠️
**问题**：Celery 默认 prefork pool 导致 CUDA 初始化失败
**解决**：使用 `--pool=solo` 单进程模式
**耗时**：2 天调试

#### 2. 坐标转换精度 ⚠️
**问题**：浮点数精度导致边界框轻微偏移
**解决**：统一使用 6 位小数精度
**耗时**：0.5 天调试

#### 3. 训练日志收集 ⚠️
**问题**：YOLO 输出到 stdout，难以捕获
**解决**：重定向 stdout/stderr 到文件
**耗时**：1 天实现
