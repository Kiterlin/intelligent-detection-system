class Dataset(Base):

    user_id: Integer (外键 -> users.id)
    created_at: DateTime

    # 关系

    batch_jobs: List[BatchJob]

##### DataFile模型
```python
class DataFile(Base):
    id: Integer (主键)
    dataset_id: Integer (外键 -> datasets.id)
    filename: String(255) - 文件名
    file_path: String(500) - 文件路径
    file_size: Integer - 文件大小（字节）
    file_type: String(20) - 文件类型（image/video）
    uploaded_at: DateTime

    # 关系
    dataset: Dataset
```

##### BatchJob模型
```python
class BatchJob(Base):
    id: Integer (主键)
    dataset_id: Integer (外键 -> datasets.id)
    user_id: Integer (外键 -> users.id)
    model_id: Integer (外键 -> ml_models.id)
    status: Enum(BatchJobStatus) - 任务状态
    total_files: Integer - 总文件数
    completed_files: Integer - 已完成文件数
    failed_files: Integer - 失败文件数
    confidence_threshold: String(10)
    iou_threshold: String(10)
    celery_group_id: String(255) - Celery任务ID
    error_message: Text
    created_at: DateTime
    started_at: DateTime
    completed_at: DateTime

    # 关系
    dataset: Dataset
    user: User
    model: MLModel
```

##### BatchJobStatus枚举
```python
class BatchJobStatus(str, enum.Enum):
    PENDING = "pending"      # 等待中
    RUNNING = "running"      # 运行中
    COMPLETED = "completed"  # 已完成
    FAILED = "failed"        # 失败
    CANCELLED = "cancelled"  # 已取消
```

### 技术亮点

1. **Celery Chain顺序处理** ⭐
   - 使用 `chain()` 而非 `group()` 实现顺序处理
   - 避免并发导致的资源争抢
   - 适合长时间运行的批量任务

2. **实时进度跟踪** ⭐
   - 前端每3秒轮询running任务
   - 后端每处理完一个文件自动更新进度
   - 进度百分比：(completed + failed) / total * 100

3. **异步文件上传** ⭐
   - 使用 `aiofiles` 异步写入文件
   - 避免阻塞主线程
   - 提升并发性能

4. **完整权限控制** ⭐
   - 用户只能访问自己的数据集
   - 所有API都验证数据集所有权
   - 级联删除保证数据一致性

5. **用户体验优化** ⭐
   - 拖拽式文件上传
   - 实时上传进度显示
