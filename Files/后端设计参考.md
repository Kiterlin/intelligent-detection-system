### 1. 🏛️ 核心技术栈 (Finalized Stack)



- **框架 (Framework):** **FastAPI**。它的异步特性 (ASGI) 是处理 I/O 密集型（如文件上传）和 AI 模型推理的完美选择。其自动数据验证 (Pydantic) 和自动文档 (Swagger UI) 将极大提高开发效率。
- **数据库 (Database):** **PostgreSQL** (生产环境) / **SQLite** (本地开发)。
- **ORM (Object-Relational Mapper):** **SQLAlchemy** (2.0 异步模式) 配合 **Alembic** (用于数据库迁移)。
- **异步任务队列 (Async Tasks):** **Celery**。这是处理耗时（如视频检测）任务的黄金标准。
- **消息代理 (Message Broker):** **Redis** (或 RabbitMQ)。用于 Celery 任务调度和（可选的）缓存。
- **认证 (Authentication):** **JWT** (JSON Web Tokens)，使用 `python-jose` 库。
- **密码哈希 (Hashing):** **Passlib** (集成 `bcrypt`)。
- **AI 模型 (AI Model):** **Ultralytics (YOLO)** 和 **PyTorch**。

### 3. 🧬 数据库模型与 Schemas (db/models.py & db/schemas.py)



这是系统的“数据骨架”。

**A. `db/models.py` (SQLAlchemy 模型 - 数据库表)**

Python

```
# (使用 SQLAlchemy 声明式基类)

class User(Base):
    __tablename__ = "users"
    id = Column(Integer, primary_key=True)
    username = Column(String, unique=True, index=True, nullable=False)
    email = Column(String, unique=True, index=True)
    hashed_password = Column(String, nullable=False)
    role = Column(String, default="user", nullable=False) # 'user' or 'admin'
    created_at = Column(DateTime, default=datetime.utcnow)
    
    # 关系
    histories = relationship("DetectionHistory", back_populates="owner")
    uploaded_models = relationship("MLModel", back_populates="uploader")

class MLModel(Base):
    __tablename__ = "ml_models"
    id = Column(Integer, primary_key=True)
    model_name = Column(String, nullable=False)
    version = Column(String)
    description = Column(Text)
    file_path = Column(String, nullable=False) # 存储在服务器上的路径
    is_active = Column(Boolean, default=False)
    uploaded_at = Column(DateTime, default=datetime.utcnow)
    
    uploader_id = Column(Integer, ForeignKey("users.id"))
    uploader = relationship("User", back_populates="uploaded_models")

class DetectionHistory(Base):
    __tablename__ = "detection_history"
    id = Column(Integer, primary_key=True)
    status = Column(String, default="pending", nullable=False) # pending, processing, completed, failed
    input_type = Column(String, nullable=False) # 'image' or 'video'
    input_file_path = Column(String, nullable=False)
    output_file_path = Column(String, nullable=True) # 结果文件路径
    result_json = Column(JSON, nullable=True) # (可选) 存储 JSON 结果
    
    owner_id = Column(Integer, ForeignKey("users.id"))
    model_id = Column(Integer, ForeignKey("ml_models.id"))
    
    owner = relationship("User", back_populates="histories")
    model = relationship("MLModel")
```

### 4. 🧠 核心业务逻辑 (Services & Tasks)



这是系统的“大脑”。



#### A. 认证 (`core/security.py`)



- `get_password_hash(password)`: 使用 `passlib` 对密码加盐 `bcrypt` 哈希。
- `verify_password(plain_password, hashed_password)`: 验证密码。
- `create_access_token(data: dict)`: 使用 `python-jose` 创建 JWT。
- `get_current_user(token: str = Depends(oauth2_scheme))` (FastAPI 依赖项):
  1. 解码 JWT 令牌。
  2. 从数据库中获取用户。
  3. 返回 `User` 模型。
- `get_current_admin_user(...)`: 类似，但额外检查 `user.role == 'admin'`。



#### B. 图片检测 (同步处理) (`services/detect_service.py`)



- `process_image(image_bytes, model_id)`:
  1. 从数据库中获取 `MLModel` 路径。
  2. **加载 YOLO 模型** (例如：`model = YOLO(model_path)`)。*（性能提示：使用 `lru_cache` 缓存已加载的模型实例）*
  3. 运行模型：`results = model(image)`。
  4. 绘制检测框 (例如：`annotated_img = results[0].plot()`)。
  5. 保存结果图片并返回其路径或字节流。
  6. 创建 `DetectionHistory` 记录 (状态为 `completed`)。



#### C. 视频检测 (异步处理) (`tasks/video_tasks.py`)



这是最关键的异步流程，它**绝不能**阻塞 API。

**1. `api/detect.py` (API 层面)**

- `POST /video` 接口 (由用户调用):
  1. (用户认证通过)
  2. 将上传的视频文件保存到一个“待处理”目录 (例如：`/storage/pending/`)。
  3. 在 `detection_history` 表中创建一条新记录：
     - `status: 'pending'`
     - `input_file_path: '.../pending/video.mp4'`
     - `owner_id: current_user.id`
     - `model_id: ...`
  4. **触发 Celery 任务：** `process_video_task.delay(history_id=new_history.id)`
  5. **立即**向用户返回 202 (Accepted) 响应，附带该任务的 `history_id`。

**2. `tasks/video_tasks.py` (Celery Worker 层面)**

- `@celery_app.task`

- `def process_video_task(history_id: int):`

  1. **[Worker 进程]** 从数据库获取 `history` 记录。

  2. **更新状态：** `history.status = 'processing'` (保存到数据库)。

  3. **加载模型：** `model = YOLO(history.model.file_path)`。

  4. **打开视频：** `cap = cv2.VideoCapture(history.input_file_path)`。

  5. **打开写入器：** `writer = cv2.VideoWriter(...)` (保存到 `/storage/completed/`)。

  6. **逐帧处理：**

     Python

     ```
     while cap.isOpened():
         ret, frame = cap.read()
         if not ret: break
         results = model(frame)
         annotated_frame = results[0].plot()
         writer.write(annotated_frame)
     ```

  7. **清理：** `cap.release()`, `writer.release()`。

  8. **更新状态：**

     - `history.status = 'completed'`
     - `history.output_file_path = '.../completed/result.mp4'`

  9. (保存到数据库)。

  10. *(如果失败，使用 `try...except` 捕获异常，将 `history.status = 'failed'` 并记录错误日志)*

### 5. 🔌 API 接口定义 (Routers)



这是前后端交互的“合同”。

- `POST /auth/login`：用户登录，返回 JWT。
- `POST /auth/register` (Admin)：管理员创建新用户。
- `GET /users/me` (User)：获取当前登录用户信息。
- `GET /admin/users` (Admin)：获取所有用户列表。
- `PUT /admin/users/{user_id}` (Admin)：更新用户信息（如角色）。
- `GET /admin/models` (Admin)：获取所有模型列表。
- `POST /admin/models/upload` (Admin)：(multipart/form-data) 上传 `.pt` 文件和元数据。
- `PUT /admin/models/{model_id}` (Admin)：更新模型（如 `is_active`）。
- `GET /models/active` (User)：获取所有 `is_active=True` 的模型列表（用于用户端下拉框）。
- `POST /detect/image` (User)：上传图片，**同步**返回检测结果。
- `POST /detect/video` (User)：上传视频，**异步**返回任务 `history_id`。
- `GET /history` (User)：获取*自己*的检测历史列表（前端轮询此接口）。
- `GET /history/{history_id}` (User)：获取单条历史记录的状态。
- `GET /admin/history` (Admin)：获取*所有*用户的检测历史（用于审计）。
